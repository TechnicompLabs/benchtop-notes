## Maui Apps
Maui (https://mauikit.org/) is a convergent UI framework by Nitrux. These are lightweight, touch-friendly apps:
* Index — File manager
* Nota — Text editor
* Station — Terminal emulator
* Clip — Video player
* Pix — Image viewer
* Shelf — Document viewer
* Communicator — Contacts manager

Note: Maui apps are Kirigami-based (KDE) and work well on both desktop and tablet form factors. Consider for the tablet mode use case.

## X-Apps (Linux Mint)
X-Apps (https://github.com/linuxmint) are GTK apps from the Linux Mint project designed to be desktop-agnostic:
* Xed — Text editor (fork of gedit/pluma)
* Xreader — Document viewer (PDF, ePub, etc.)
* Xviewer — Image viewer
* Xplayer — Video player
* Pix — Image organizer

Note: These are simpler/more traditional than GNOME apps and may appeal to users who dislike GNOME's opinionated design. Probably not needed if shipping full GNOME + KDE apps.
