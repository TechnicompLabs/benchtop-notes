# Security Tools

## Reverse Engineering and Analysis
* Ghidra — Disassembler/Decompiler
* imHex — Hex editor
* [Seer](https://github.com/epasveer/seer) — GDB GUI
* VSCode
* GDB

## Network Analysis
* Wireshark / termshark (TUI)
* Mitmproxy — MITM proxying
* Zenmap / Nmap — Network scanning

## Forensics
* Sleuthkit — Disk forensics
* Autopsy — Forensic browser
* Volatility — Memory dump analyzer w/ entropy scanner

## Misc
* Cyberchef — Data transformation/encoding
* [devtui](https://github.com/skatkov/devtui) — Developer TUI
* Hashcat (https://hashcat.net/) — GPU-accelerated password cracking/auditing (replaces L0phtcrack, which is Windows-only and effectively abandoned)
* John the Ripper (https://www.openwall.com/john/) — CPU-based password auditing
* KVM/QEMU — Virtualization for analysis
* Fail2ban — Intrusion prevention

## Categories (High Level)
* Exploit Scanning
* Web Security Scanning
* MITM Proxying
* Memory Dump Analyzer w/ Entropy Scanner
* Disk Forensics Tools
* OS Hash-check Installs
